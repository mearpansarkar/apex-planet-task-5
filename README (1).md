## What each task delivered
1. **Wrangling:** profiled the data and fixed missing values (20 ages, 13 cities), 8 repeated order IDs and reused customer IDs. Produced a data dictionary, a reproducible cleaning script and an analysis-ready dataset with 12 engineered columns.
2. **EDA & BI:** descriptive statistics, 7 SQL business questions (joins, aggregation, window functions) and multivariate charts. Total revenue is 139.4M with Electronics at 36.4%. Built a static KPI dashboard mock-up in Excel.
3. **Deep-dive & dashboard:** defined 5 KPIs and segmented orders into 4 buyer types by price and quantity. Big Spenders are 24% of orders but 52.5% of revenue. Built an interactive dashboard with five filters.
4. **Story & validation:** 7-slide stakeholder deck and 8 hypothesis tests. Only the revenue concentration finding held up (95% CI 48.6% to 56.4%); the Q4, gender, age and category differences were not statistically significant.

## Technical skills demonstrated
- **Python:** pandas, NumPy, matplotlib, seaborn, SciPy
- **SQL (SQLite):** joins, CTEs, window functions, aggregation
- **Excel:** formulas, KPI dashboards, charts
- **Data cleaning and EDA:** profiling, imputation, outlier flags, feature engineering
- **Statistics:** Welch t-test, ANOVA, chi-square, correlation, binomial test, bootstrap confidence intervals
- **Dashboarding:** interactive HTML dashboard with Chart.js
- **Communication:** data storytelling, stakeholder presentations, video walkthroughs
- **Tooling:** Git and GitHub
